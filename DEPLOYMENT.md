# QuikImpo Deployment Guide

## 🚀 Backend Deployment (Railway)

### Step 1: Create Railway Account
1. Go to [railway.app](https://railway.app)
2. Sign up with GitHub account (recommended)
3. Create a new project

### Step 2: Connect Your GitHub Repository
1. In Railway dashboard, click "New Project"
2. Select "Deploy from GitHub repo"
3. Choose your `quikimpo` repository
4. Select the `quikimpo-backend/quikimpo-main` directory as root

### Step 3: Configure PostgreSQL Database
1. In Railway project, click "Add Service"
2. Select "PostgreSQL"
3. The `DATABASE_URL` will be automatically created as an environment variable

### Step 4: Set Environment Variables
In Railway dashboard, go to your Django service and add these variables:

```
DEBUG=False
SECRET_KEY=generate-a-secure-key-or-use-django-insecure-key
ALLOWED_HOSTS=yourdomain.railway.app,.yourdomain.com
DATABASE_URL=postgresql://... (auto-generated by Railway PostgreSQL)
CORS_ALLOWED_ORIGINS=https://yourdomain.vercel.app
ANTHROPIC_API_KEY=sk-ant-xxxxx
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-specific-password
```

### Step 5: Deploy
1. Railway auto-deploys on every git push to `main`
2. Check deployment status in the "Deployments" tab
3. View logs in the "Logs" tab

### Step 6: Run Database Migrations
1. Open "Command Palette" in Railway project
2. Run: `python manage.py migrate`
3. Optionally load fixtures: `python manage.py loaddata freight/fixtures/demo_shipments.json`

### Your Backend URL
Once deployed: `https://your-project-name.up.railway.app`

## 🎨 Frontend Deployment (Vercel)

### Step 1: Create Vercel Account
1. Go to [vercel.com](https://vercel.com)
2. Sign up with GitHub (recommended)

### Step 2: Deploy Frontend
1. Click "New Project"
2. Import your `quikimpo` GitHub repository
3. Set the root directory to: `quikimpo-frontend/quikimpo-frontend`
4. Vercel will auto-detect Vite settings

### Step 3: Configure Environment Variables
In Vercel project settings → "Environment Variables", add:

```
VITE_API_BASE_URL=https://your-project-name.up.railway.app/api
```

Replace `your-project-name` with your actual Railway project name.

### Step 4: Deploy
1. Click "Deploy"
2. Vercel will build and deploy automatically
3. Monitor build logs in the "Deployments" tab

### Your Frontend URL
Once deployed: `https://quikimpo-frontend.vercel.app`

## 🔗 Connect Backend & Frontend

### Update CORS on Railway Backend
1. Railway → Django service → Variables
2. Update: `CORS_ALLOWED_ORIGINS=https://quikimpo-frontend.vercel.app`

### Update API URL on Vercel Frontend
1. Vercel → Frontend project → Settings → Environment Variables
2. Update: `VITE_API_BASE_URL=https://your-railway-project.up.railway.app/api`

## 🔐 Security Best Practices

### Generate Strong SECRET_KEY
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

### Email Setup (Gmail)
1. Enable 2FA on Gmail
2. Generate [App Password](https://myaccount.google.com/apppasswords)
3. Use app password in `EMAIL_HOST_PASSWORD`

### API Keys
- Keep `ANTHROPIC_API_KEY` private (only in Railway, never in code)
- Rotate keys regularly
- Use Railway's secret management

## 🐛 Troubleshooting

### Database Connection Error
```
Check DATABASE_URL format: postgresql://user:password@host:port/dbname
```

### CORS Error
```
Verify CORS_ALLOWED_ORIGINS includes your Vercel frontend URL
```

### Build Fails on Vercel
```
Check Node version: package.json
Verify build command: npm run build
Check for environment variables used during build
```

### Static Files Not Loading
```
Ensure WhiteNoise is installed in requirements.txt
Run: python manage.py collectstatic
```
